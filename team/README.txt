TEAM PHOTOS (About page)
========================
Place the photos in this folder using exactly these file names:

  cynthia-cerezo.jpg
  erwin-sister.jpg
  richel-laya.jpg
  jomar-banda.jpg
  angel-bayle.jpg

- .jpg, .jpeg, .png and .webp are all accepted (one file per person).
- A square photo (for example 600x600) with the face centered works best.
  The page crops it to a circle automatically.
- Until a photo is added, the person's initials are shown instead.
- After uploading, hard refresh the page (Ctrl+F5).
