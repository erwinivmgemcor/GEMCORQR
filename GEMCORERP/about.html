Newly updated

Now running on Supabase.

GEMCOR ERP now runs on Supabase, a PostgreSQL database that serves as the single source of truth for stock, requests and the ledger across every device.

  • Single source of truthWarehouse, production, procurement and finance all see the same data.
  • All-or-nothing transactionsEditing or voiding an MRR, cancelling an MRIF and creating a PRF either save completely or not at all.
  • Duplicate-proof stock ledgerEvery stock movement is recorded once in an insert-only ledger.
  • Audit trailEvery edit and correction records a reason, the user and a timestamp.
  • Ledger Cost FreezePast transactions keep their original cost when an item’s price changes.
  • Admin Console and System HealthInspect database tables and connection status without leaving the system.
