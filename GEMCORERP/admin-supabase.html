📖 Admin Guide

Komprehensibong guide para sa lahat ng admin tasks. Hindi mo na kailangan pumunta sa Supabase para sa common operations.

Quick Actions
🚀 Getting Started
Admin Console Overview

Ang Supabase Admin Console ay para sa system administrators. Dito mo pwedeng gawin ang lahat ng data operations na hindi mo kailangan pumunta sa Supabase.

Access: Kailangan mo ng ivm_isAdmin = true para makapasok.
Access Modes Explained
Mode Pwedeng Gawin Safe?

📊 Data Management
Restore Unit Cost from Snapshot

Gamitin ito kung nawala o naging zero ang unit costs ng items — kadalasan nangyayari pagkatapos ng cutover na may blank CSV.

  1. Pumunta sa Supabase SQL Editor
  2. I-run ang SQL sa ibaba
  3. Palitan ang 4 ng tamang snapshot ID (i-check sa Cutover History)
WITH snapshot_data AS (
  SELECT 
    (item->>'item_code') AS item_code,
    (item->>'unit_cost')::NUMERIC AS unit_cost
  FROM erp_cutover_snapshots,
       jsonb_array_elements(items_data) AS item
  WHERE id = 4
    AND (item->>'unit_cost')::NUMERIC > 0
)
UPDATE erp_items 
SET unit_cost = sd.unit_cost, updated_at = NOW()
FROM snapshot_data sd
WHERE erp_items.item_code = sd.item_code
  AND erp_items.is_deleted = false;
Fix Malformed Item Codes

Kung may items na may weird na item_code (may commas, spaces, etc.), i-clean mo sila.

-- View malformed items
SELECT item_code, description 
FROM erp_items 
WHERE item_code LIKE ',%'
   OR item_code LIKE '% %'
   OR item_code IS NULL
   OR item_code = ''
LIMIT 20;

🔧 Troubleshooting
❌ Stock Value = ₱0

Cause: Lahat ng unit_cost ay zero.

Fix:

  1. Pumunta sa Cutover History — hanapin ang snapshot na may valid cost
  2. I-restore via SQL (tingnan ang Data Management section)
  3. I-refresh ang Stock Monitor
❌ Row Click Hindi Gumagana

Cause: Missing onclick sa table row.

Fix: I-clear ang cache at i-refresh:

❌ Edit Button Not Working

Cause: Naka-Read-Only mode, o missing modal.

Fix:

  1. Check mo kung Read + Write ang mode
  2. Refresh ang browser
  3. Check ang console (F12) for errors
❌ Cutover Failed: "column does not exist"

Cause: Luma ang SQL function sa Supabase.

Fix: I-re-run ang latest SQL function — tingnan ang Full Cutover tab.

❌ Only 1000 Items Loaded

Cause: Supabase 1000-row limit per request.

Fix: Ang pagination loop ay naka-set na sa latest code. I-check kung may 2,389 items sa Stock Monitor.

❌ Template Downloaded is Blank

Cause: Walang data sa erp_items, o wrong filter.

Fix: I-check ang total items count sa Stock Monitor. Dapat 2,389.

🚨 Emergency Procedures
ATTENTION: Ang mga procedures na ito ay destructive. Siguraduhin na may backup bago mag-execute.
🚨 Emergency Stop (Read-Only Mode)

I-set ang system sa Read-Only para walang makapag-modify habang may issue.

🔄 Reset All Transactions

I-delete lahat ng transactions (documents, PRF, etc.) pero i-keep ang master data (items, users).

💾 Emergency Backup

I-create ng immediate backup ng lahat ng data.

🔙 Rollback Last Cutover

I-undo ang last cutover kung may issue.

📋 Common Tasks
📥 Paano Mag-Add Ng Bagong Item
  1. Pumunta sa Stock Monitor
  2. Click ang "+ Add New Item"
  3. Fill-in ang: Item Code, Description, Category, Location, Unit, Cost
  4. Click "Save Item"
📤 Paano Mag-Bulk Import Ng Items
  1. Pumunta sa Stock Monitor
  2. Click "Bulk Import"
  3. Download ang template
  4. I-fill ang data
  5. Upload at i-confirm
📊 Paano Mag-Run Ng Cutover
  1. Pumunta sa Full Cutover tab
  2. Click "Download Current as Template"
  3. I-edit ang data (i-keep ang Unit Cost column!)
  4. Upload ang CSV
  5. Review ang diff (Add/Update/Remove)
  6. Type "CUTOVER" para mag-execute
  7. Auto-snapshot gagawin
🔙 Paano Mag-Rollback Ng Cutover
  1. Pumunta sa Full Cutover tab
  2. Scroll down sa Cutover History
  3. Hanapin ang snapshot na gusto mong balikan
  4. Click ang 🔄 Rollback icon
  5. Type "ROLLBACK" para mag-confirm
👥 Paano Mag-Add Ng Bagong User
  1. Pumunta sa User Management
  2. Click "Add User"
  3. Fill-in: Username, Password, Full Name, Department, Roles
  4. Optional: Check "Grant Admin Access"
  5. Click "Create User"

Admin PIN

Ang PIN ay kailangan para sa Full Access mode at destructive actions.

  • Default: 9999 (palitan agad!)
  • 4-digit number lang
  • Naka-save sa browser localStorage
  • Hindi naka-share sa server
Audit Trail

Lahat ng admin actions ay naka-log sa admin_audit_log table:

  • INSERT, UPDATE, DELETE actions
  • Raw SQL executions
  • Cutover executions
  • Rollback operations
💡 Best Practices
✅ DO's
  • ✅ Backup bago mag-major operation (cutover, reset)
  • ✅ I-check ang diff bago mag-execute ng cutover
  • ✅ I-keep ang Unit Cost column sa CSV
  • ✅ Regular backup — every Friday
  • ✅ Use Read + Write mode for daily work
  • ✅ Test sa ilang items muna bago mag-full cutover
❌ DON'Ts
  • ❌ Huwag mag-delete ng items without backup
  • ❌ Huwag i-blank ang Unit Cost sa CSV — maging 0
  • ❌ Huwag mag-execute ng cutover kung may unresolved issue
  • ❌ Huwag i-share ang admin PIN
  • ❌ Huwag mag-run ng Raw SQL kung hindi 100% sure
  • ❌ Huwag mag-reset ng transactions without double-checking
